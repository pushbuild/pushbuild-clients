# Federal contracts won by public companies (weekly)

US federal contract awards of $1M or more with activity in the last 7 days, matched to the winning company's stock ticker and SEC CIK.
One CSV per week; `latest.csv` is the newest. Updated every Monday. Last update: 2026-10-26 (69 awards).

Source: [USAspending.gov](https://www.usaspending.gov/) (public domain), joined to SEC EDGAR tickers by normalized recipient name.
Contracts won by subsidiaries under a different name are not matched.

Query any ticker or date range live with the [Federal Contracts by Stock Ticker API](https://pushbuild.com/apis/federal-contracts-by-ticker/).
